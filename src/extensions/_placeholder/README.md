# _placeholder

Это шаблон для будущего расширения библиотеки CosmicEye.

## Структура расширения

Каждое расширение должно содержать:

```
src/extensions/<extension-name>/
  index.ts       — публичные экспорты расширения
  README.md      — описание назначения и API расширения
  ...            — внутренние модули
```

## Правила

- Расширение **не должно** модифицировать ядро.
- Расширение может импортировать публичные типы.
- Каждое расширение должно быть реэкспортировано из `src/extensions/index.ts`.
- Тесты расширения размещаются в `tests/extensions/<extension-name>/`.
